## Function names / constants

Function name should be verbs, not nouns. A function is an action, not a thing. Dont use **Vietnamese** in function names or constants.

```python
  //bad
  def lay_danh_sach_nhan_vien():
      pass

  // good
  def get_employee_list():
      pass

```
