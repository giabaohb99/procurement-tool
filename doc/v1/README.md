|---|---|

**V1 còn chạy ở thumua.degoholding.vn tới đợt Đ-15, KHÔNG nhận tính năng mới** (`frontend/` đóng băng từ 13/08/2026).
Tài liệu ở đây là yêu cầu gốc tháng 6–7, thiết kế giao diện cũ, kịch bản kiểm thử cũ và dữ liệu mẫu — đọc để tra lịch sử,
đừng coi là yêu cầu hiện tại. Luật nghiệp vụ thu mua còn đúng cho cả hai bản nằm ở [`../erp/thu-mua/`](../erp/thu-mua/README.md).

| Thư mục / tệp | Nội dung |
|---|---|
| `yeu-cau/` | Yêu cầu nghiệp vụ gốc (Requirement_*) |
| `thiet-ke/` | Thiết kế giao diện cũ, dashboard |
| `kiem-thu/` | Kịch bản kiểm thử tay của V1 |
| `phan-quyen/` | Kế hoạch và kịch bản kiểm phân quyền thời V1 |
| `chung/` | Tham chiếu dev cũ: deploy VPS, checklist, quy ước đặt tên V1 (luật hiện hành ở `.claude/rules/chung-dat-ten-va-quy-uoc.md`) |
| `du-lieu/` | Dữ liệu mẫu (`datamau/`), bảng gốc (`sheet/`), danh sách tính năng (xlsx) |
| `tasks.md`, `task-process.md` | Checklist tiến độ và quy trình làm việc thời V1 |
